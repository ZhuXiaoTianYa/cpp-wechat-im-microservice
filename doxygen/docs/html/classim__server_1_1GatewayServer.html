详细描述

网关服务器主类

集成HTTP服务器和WebSocket服务器，提供统一的对外接口，负责：

  • HTTP请求路由到后端微服务
  • WebSocket长连接管理
  • 用户会话管理（Redis）
  • 实时消息推送
  • 服务发现与负载均衡
