# 完整配置和运行指南

## 环境要求

| 要求 | 版本 |
|------|------|
| Node.js | >= 18.0.0 |
| pnpm | >= 8.0.0 |

## 项目初始化

### 1. 克隆项目

```bash
git clone <repository_url>
cd web
```

### 2. 安装依赖

```bash
pnpm install
```

## 配置说明

### 环境变量配置

在项目根目录创建 `.env.development` 文件：

```env
VITE_API_BASE_URL=http://localhost:9000
VITE_WS_URL=ws://localhost:9001
VITE_APP_TITLE=IM 即时通讯
```

**说明：**

- `VITE_API_BASE_URL`: 后端 API 地址
- `VITE_WS_URL`: WebSocket 服务器地址
- `VITE_APP_TITLE`: 应用标题

### 生产环境配置

创建 `.env.production` 文件：

```env
VITE_API_BASE_URL=https://your-api-domain.com
VITE_WS_URL=wss://your-ws-domain.com
VITE_APP_TITLE=IM 即时通讯
```

## 运行项目

### 开发模式

```bash
pnpm dev
```

启动后访问 http://localhost:3000

### 生产构建

```bash
pnpm build
```

构建产物输出到 `dist` 目录。

### 预览构建

```bash
pnpm preview
```

预览生产环境构建结果。

## 开发指南

### 添加新的 API 接口

1. 在 `src/api/` 目录下创建或编辑对应的模块文件
2. 使用 `apiClient` 发送请求
3. 导入 `im_server` 使用 Protobuf 编解码

示例：

```typescript
// src/api/example.ts
import { apiClient } from './client';
import { im_server } from '@/proto/generated';
import { makeRequestId } from '@/utils/id-generator';

export const exampleApi = async (params: ExampleParams): Promise<ExampleResponse> => {
  const req = im_server.ExampleReq.create({
    requestId: makeRequestId(),
    ...params,
  });

  const resp = await apiClient.post<ExampleResponse>(
    '/ExampleService/api',
    { protobufType: 'ExampleReq', data: req.toBinary() },
    { headers: { 'x-protobuf-type': 'ExampleRsp' } }
  );

  return resp.data;
};
```

### 添加新的组件

1. 在 `src/components/` 目录下创建组件文件
2. 使用 TypeScript 定义 Props 接口
3. 导出组件供页面使用

示例：

```typescript
// src/components/example/ExampleComponent.tsx
import { FC } from 'react';

interface Props {
  title: string;
  onClick?: () => void;
}

export const ExampleComponent: FC<Props> = ({ title, onClick }) => {
  return (
    <div className="p-4" onClick={onClick}>
      {title}
    </div>
  );
};
```

### 添加新的 Store 状态

在 `src/store/useIMStore.ts` 中添加：

```typescript
interface IMStore {
  // ... 现有状态
  newState: NewType;

  // ... 现有 actions
  setNewState: (value: NewType) => void;
}

// 在 immer 中添加
persist(
  immer((set) => ({
    // ...
    newState: initialValue,
    setNewState: (value) => set({ newState: value }),
  })),
  { name: 'im-storage' }
)
```

## 故障排查

### 问题：依赖安装失败

**解决方案：**

```bash
rm -rf node_modules pnpm-lock.yaml
pnpm install
```

### 问题：TypeScript 类型错误

**解决方案：**

```bash
pnpm typecheck
```

### 问题：Vite 热更新不工作

**解决方案：**

1. 检查是否修改了 `vite.config.ts`
2. 重启开发服务器

### 问题：API 请求失败

**解决方案：**

1. 检查 `.env.development` 配置
2. 确认后端服务是否运行
3. 检查浏览器控制台网络请求
