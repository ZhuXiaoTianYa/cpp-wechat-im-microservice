## 🚀 现在可以运行项目了

### 1. 安装依赖

```bash
cd /home/zhutian/client/web
pnpm install
```

### 2. 生成 Protobuf 类型

```bash
pnpm run proto:gen
```

这会生成：
- `src/proto/generated.js`
- `src/proto/generated.d.ts`

### 3. 启动开发服务器

```bash
pnpm run dev
```

访问 http://localhost:3000

## 🔧 可能遇到的问题

### 问题 1: pnpm 未安装

```bash
npm install -g pnpm
```

### 问题 2: proto 文件路径错误

如果 `pnpm run proto:gen` 报错，检查 proto 文件路径：

```bash
ls ../../repositories/gitee/cpp-wechat-im-microservice/code/server/proto/
```

如果路径不对，修改 `package.json` 中的 `proto:js` 脚本。

### 问题 3: 端口被占用

如果 3000 端口被占用，修改 `vite.config.ts` 中的端口号。
