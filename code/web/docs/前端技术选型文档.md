# 前端技术选型文档

## 一、技术选型决策

### 1. 核心框架：React 19 + TypeScript 5.x

**选型理由：**

- React 19 提供更好的性能和新的 Hook
- TypeScript 5.x 提供完整的类型安全
- 配合 Vite 6.x 享受极速的开发体验

### 2. 状态管理：Zustand 4.x

**选型理由：**

- 轻量级状态管理库（比 Redux 简单得多）
- 内置 Immer 支持，方便 immutable 更新
- 内置 Persist 中间件，支持 localStorage 持久化
- TypeScript 友好

**核心实现：**

```typescript
import { create } from 'zustand';
import { immer } from 'zustand/middleware/immer';
import { persist } from 'zustand/middleware';

interface IMStore {
  user: UserInfo | null;
  sessionId: string | null;
  sessions: Map<string, ChatSession>;
  messages: Map<string, Message[]>;
  friends: Map<string, UserInfo>;
  pendingFriendRequests: IFriendEvent[];
  wsConnected: boolean;
  wsReconnecting: boolean;
  reconnectAttempts: number;
}

export const useIMStore = create<IMStore>()(
  persist(
    immer((set) => ({
      // 初始状态和 actions
    })),
    { name: 'im-storage' }
  )
);
```

### 3. HTTP 客户端：Axios 1.x + Protobuf

**选型理由：**

- Axios 是最流行的 HTTP 客户端
- 支持请求/响应拦截器
- 支持 Protobuf 序列化/反序列化
- 配合 protobufjs 进行编解码

**核心实现：**

```typescript
// API 客户端配置
const apiClient = axios.create({
  baseURL: '/service',
  timeout: 30000,
});

// 请求拦截器：添加 Protobuf 数据
apiClient.interceptors.request.use((config) => {
  const requestData = config.data;
  if (requestData && typeof requestData === 'object') {
    const { protobufType, data } = requestData;
    if (protobufType && data) {
      config.data = Buffer.from(data);
      config.headers['x-protobuf-type'] = protobufType;
    }
  }
  return config;
});

// 响应拦截器：解析 Protobuf 数据
apiClient.interceptors.response.use(
  (response) => {
    const protobufType = response.headers['x-protobuf-type'];
    if (protobufType && response.data) {
      return Protobuf.decode(protobufType, response.data);
    }
    return response;
  }
);
```

### 4. WebSocket：原生 WebSocket API

**选型理由：**

- 不需要额外的库，原生支持
- 配合 Protobuf 进行二进制传输
- 实现心跳检测和自动重连

**核心实现：**

```typescript
export class IMWebSocket {
  private ws: WebSocket | null = null;
  private reconnectDelay = 1000;
  private maxReconnectDelay = 30000;

  connect(sessionId: string) {
    this.ws = new WebSocket(this.wsUrl);
    this.ws.onmessage = async (event) => {
      const blob = await event.data.blob();
      const notify = im_server.NotifyMessage.decode(new Uint8Array(buffer));
      handleNotifyMessage(notify);
    };
  }

  // 指数退避重连
  private scheduleReconnect() {
    this.reconnectDelay = Math.min(this.reconnectDelay * 2, this.maxReconnectDelay);
    setTimeout(() => this.connect(this.sessionId), this.reconnectDelay);
  }
}
```

### 5. 样式方案：Tailwind CSS v4

**选型理由：**

- 原子化 CSS，快速构建 UI
- 支持自定义微信风格配色
- 与微信设计规范一致

**配色方案：**

| 变量名 | 颜色值 | 用途 |
|--------|--------|------|
| `--wechat-primary` | #07C160 | 主题绿 |
| `--wechat-bg-gray` | #EDEDED | 背景灰 |
| `--wechat-bubble-self` | #95EC69 | 自己消息气泡 |
| `--wechat-bubble-other` | #FFFFFF | 对方消息气泡 |

### 6. 路由：React Router 7

**选型理由：**

- React 官方推荐的路由库
- 支持嵌套路由
- TypeScript 友好

**核心实现：**

```typescript
export default function AppRoutes() {

```

- 高效的二进制序列化

## 二、技术架构

### 分层架构

```
┌─────────────────────────────────┐
│         Pages (页面层)           │
│  LoginPage, ChatPage, etc.      │
├─────────────────────────────────┤
│       Components (组件层)        │
│  SessionList, ChatArea, etc.    │
├─────────────────────────────────┤
│        Store (状态层)            │
│  useIMStore (Zustand)          │
├─────────────────────────────────┤
│       Services (服务层)          │
│  WebSocket, MessageHandler      │
├─────────────────────────────────┤
│        API (接口层)              │
│  user.ts, friend.ts, message.ts │
├─────────────────────────────────┤
│       Proto (协议层)              │
│  im_server (Generated)         │
└─────────────────────────────────┘
```

### 数据流

1. 用户操作 → 组件触发
2. 组件调用 API 或 Store action
3. API 发送 HTTP 请求或 WebSocket 消息
4. 服务端响应 → Store 更新
5. 组件自动重新渲染

## 三、性能优化

### 1. 状态管理优化

- 使用 Immer 避免不必要的对象复制
- 使用 Persist 中间件持久化必要状态
- 合理拆分状态，避免不必要的重渲染

### 2. WebSocket 优化

- 指数退避重连策略
- 心跳检测机制
- 二进制传输减少网络开销

### 3. UI 优化

- Tailwind CSS 按需生成
- 组件懒加载
- 合理使用 React.memo
