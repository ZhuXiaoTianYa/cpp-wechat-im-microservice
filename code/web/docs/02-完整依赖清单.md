## 安装命令

```bash
cd d:\项目\web

pnpm install

pnpm run proto:gen
```

## 依赖更新策略

1. **核心依赖** (React、TypeScript、Vite)：跟随 LTS 版本
2. **UI 框架** (Tailwind CSS)：及时更新以获取新特性
3. **Protobuf**：锁定版本，避免与后端不兼容
4. **其他依赖**：每月检查一次安全更新

## 包体积说明

生产构建时的预估包体积：

- React + React DOM: ~140KB (gzipped)
- Zustand: ~3KB
- Axios: ~15KB
- Protobufjs: ~40KB
- Tailwind CSS: ~10KB (purged)
- Lucide React: ~30KB (tree-shaken)
- Sonner: ~10KB
- 其他: ~20KB

**总计**: ~270KB (gzipped)

## 浏览器兼容性

支持的浏览器版本：

- Chrome >= 90
- Firefox >= 88
- Safari >= 14
- Edge >= 90

不支持 IE 11（Vite 不支持）
