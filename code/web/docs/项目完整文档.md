## 项目概述

### 项目简介

基于 React 19 + TypeScript 的微信风格即时通讯 Web 应用，支持用户登录注册、好友管理、即时消息、文件传输等功能。

### 功能列表

- ✅ 用户登录/注册
- ✅ 好友管理（添加、同意/拒绝、删除）
- ✅ 即时消息（文本、图片、文件）
- ✅ 实时 WebSocket 推送
- ✅ 消息已读/未读状态
- ✅ 聊天会话管理
- ✅ 好友申请通知
- ✅ 响应式设计

## 技术栈详解

### 1. React 19 + TypeScript

- 完整的类型安全
- React 19 新特性支持
- 配合 Vite 享受极速开发

### 2. Zustand 状态管理

核心 Store：`src/store/useIMStore.ts`

```typescript
interface IMStore {
  user: UserInfo | null;
  sessionId: string | null;
  sessions: Map<string, ChatSession>;
  messages: Map<string, Message[]>;
  friends: Map<string, UserInfo>;
  pendingFriendRequests: IFriendEvent[];
  wsConnected: boolean;
  wsReconnecting: boolean;
  reconnectAttempts: number;

```

特点：

- Immer 中间件支持 immutable 更新
- Persist 中间件支持 localStorage 持久化
- TypeScript 友好

## WebSocket 通信

### 连接流程

1. 用户登录成功后获取 `sessionId`
2. 调用 `imWebSocket.connect(sessionId)` 建立连接
3. 发送鉴权消息
4. 接收服务器推送的消息

### 消息类型

| 消息类型 | 说明 |
|----------|------|
| `CHAT_MESSAGE_NOTIFY` | 新消息通知 |
| `FRIEND_ADD_APPLY_NOTIFY` | 好友申请通知 |
| `FRIEND_ADD_PROCESS_NOTIFY` | 好友申请处理通知 |
| `CHAT_SESSION_CREATE_NOTIFY` | 新会话通知 |
| `FRIEND_REMOVE_NOTIFY` | 好友删除通知 |

### 重连策略

- 初始延迟：1 秒
- 最大延迟：30 秒
- 退避策略：指数增长（每次 × 2）

## 状态管理

### Store 结构

```typescript
interface IMStore {
  // 用户信息
  user: UserInfo | null;
  sessionId: string | null;

  // 会话
  sessions: Map<string, ChatSession>;

  // 消息
  messages: Map<string, Message[]>;

  // 好友
  friends: Map<string, UserInfo>;
  pendingFriendRequests: IFriendEvent[];

  // WebSocket 状态
  wsConnected: boolean;
  wsReconnecting: boolean;
  reconnectAttempts: number;
}
```

### Actions

```typescript
// 用户
setUser(user: UserInfo | null): void;
setSessionId(sessionId: string | null): void;
logout(): void;

// 会话
setSessions(sessions: ChatSession[]): void;
updateSession(session: ChatSession): void;

// 消息
setMessages(sessionId: string, messages: Message[]): void;
addMessage(sessionId: string, message: Message): void;

// 好友
setFriends(friends: UserInfo[]): void;
addFriend(friend: UserInfo): void;
removeFriend(friendId: string): void;
addPendingFriendRequest(event: IFriendEvent): void;
removePendingFriendRequest(eventId: string): void;

// WebSocket
setWSStatus(connected: boolean, reconnecting: boolean): void;
resetReconnectAttempts(): void;
incrementReconnectAttempts(): void;
```
