## 1. 核心框架：React 19.x + TypeScript 5.x

### 推荐理由

1. **Actions 和 useTransition 优化 IM 场景**  
   React 19 的 Actions、useOptimistic 和改进的 Suspense 能显著提升消息发送的用户体验，支持乐观更新和自动错误处理

2. **生态成熟度最高**  
   你已使用的 Radix UI、Lucide React、React Router 都已支持 React 19，无迁移成本

3. **Hooks 天然适配 WebSocket**  
   useEffect + useRef 可优雅管理 WebSocket 长连接生命周期，新增的 use() Hook 简化异步数据处理

### React 19 新特性对 IM 的优势

- **useOptimistic**: 消息发送时立即显示，失败后自动回滚
- **useActionState**: 简化表单提交状态管理（登录、注册）
- **use() Hook**: 简化 Promise 和 Context 的使用
- **ref 作为 prop**: 不再需要 forwardRef
- **改进的 Suspense**: 更好的加载状态处理

### 核心依赖

## 2. 状态管理：Zustand 4.x

### 推荐理由

1. **轻量级零样板代码** - 无需 actions/reducers/middleware
2. **原生支持 Immer** - 安全地"直接修改"嵌套状态
3. **完美配合 WebSocket** - store 外部直接调用 setState

### 核心依赖

```json
{
  "dependencies": {
    "zustand": "^4.5.0",
    "immer": "^10.1.0"
  }
}
```

## 3. HTTP/WebSocket 请求库

### HTTP: Axios 1.7.x

- 原生支持二进制 (responseType: 'arraybuffer')
- 拦截器统一处理 Protobuf 序列化/反序列化
- 取消请求机制适合搜索场景

### WebSocket: 原生 API + 自定义封装

- 无需额外依赖，完全控制重连逻辑
- 自定义心跳、断线重连、消息队列
- 与 Zustand 无缝集成

```json
{
  "dependencies": {
    "axios": "^1.7.0"
  }
}
```

---

## 4. Protobuf 编解码：protobufjs 7.x

### 推荐理由

1. **浏览器原生支持最佳** - 纯 JS 实现，包体积小 (~40KB)
2. **动态加载 .proto 文件** - 开发阶段快速迭代
3. **完整 TypeScript 支持** - pbts 工具生成 .d.ts

```json
{
  "dependencies": {
    "protobufjs": "^7.4.0"
  },
  "devDependencies": {
    "protobufjs-cli": "^1.1.0"
  }
}
```
